# Liltloom 小红书发布文案

## 标题

我做了一个让 AI 慢慢学会你写作方式的开源插件

## 正文

我一直觉得，“按我的风格写”这件事，现在的操作方式有点别扭。

每开一个新对话，就要把那段越来越长的风格 Prompt 再复制一次；写短了，AI 学不像；写长了，又占上下文。更麻烦的是，这些偏好没有真正积累下来——今天纠正过的语气、结构和用词，下一次还要重新解释。

所以我做了 Liltloom，中文名叫「语织」。

它想做的不是再生成一段万能 Prompt，而是把“你的写作方式”变成一层由你拥有、可以持续积累的数据：平时安静地从合格的本人表达中提取风格信号，需要 AI 模仿你时，再按当前任务编译出一份很短的 Style Context Packet。

几个我比较在意的设计：

1. 自动学习，但默认不保存完整对话原文。基础模式只累计统计特征和结构化规则。
2. 学到的东西不是黑盒。每条规则都可以查看、修改、锁定、忽略或删除；也能导出为可读 JSON，自己编辑和迁移。
3. 默认不会偷偷改变每一次回答。只有你主动取用，或通过明确授权的接口调用时，风格信息才会进入当前写作任务。
4. 使用前可以预览。你能看到这次到底会交给 AI 哪些规则、预计占多少 token。
5. 更精准的原文片段和小模型精炼是两个独立的高级开关，会明确提示额外存储、模型调用和成本风险。
6. Liltloom 本身是可移植的风格记忆层。DeepSeek Harness 是第一个、也是目前适配最完整的宿主，不会把数据格式锁死在某一个 Agent 框架里。

现在还是一个很早期的开源 MVP，但完整的设置界面、规则管理、风格预览、JSON 导入导出和删除控制已经可以使用。

如果你也受够了反复复制“请模仿我的风格”那一大段提示词，欢迎来试试，也欢迎告诉我：你最希望 AI 长期记住自己的哪一种表达习惯？
