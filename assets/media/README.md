## 封面生成说明

封面使用 OpenAI 内置图像生成能力制作。核心提示要求是：竖版 3:4、温暖米白背景、炭黑与靛蓝主色，两条织线把零散短句汇聚成对话气泡；准确呈现“Liltloom 语织”“让 AI 写得更像你”“不用再复制风格 Prompt”“自动学习 · 轻量 · 无感 · 显式取用”，避免机器人、赛博朋克、密集 UI 和第三方标志。最终版本在品牌名左侧加入了与产品界面一致的双线织结 Logo，并用轻羽图标表达“轻量 · 无感”，其余构图保持不变。
